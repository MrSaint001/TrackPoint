How it works

1. Register the device Enter a name, choose the device type and provide its device code.
2. Open the phone connection page After adding the device, use its QR code to open the TrackPoint phone connection page.
3. Allow location On the phone, allow browser location permission so TrackPoint can receive its GPS coordinates.
4. Track the device Return to Phone Tracker to see the latest reported location on the map.
